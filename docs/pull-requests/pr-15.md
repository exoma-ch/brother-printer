# [PR 15](https://github.com/exoma-ch/brother-printer/pull/15) feat: USB transport layer with discover for PT-E920BT

## Description

Implements the USB transport layer for the PT-E920BT on Linux using pyusb/libusb, including printer discovery, a `Transport` protocol, robust error mapping with udev hints, and a `brother-printer discover` CLI subcommand. Also includes devcontainer USB passthrough, udev rules, a Linux USB setup guide, and the fixes/refinements from live PT-E920BT hardware verification (kernel-driver detach ordering, rootless Podman permissions, confirmed product ID `0x224B`).

## Changes Made

- `src/brother_printer/transport/` -- new transport package
  - `base.py`: `Transport` protocol and `PrinterInfo` dataclass
  - `errors.py`: transport exceptions with udev hint
  - `usb.py`: `UsbTransport` (pyusb bulk I/O) and `discover()`; kernel driver detached before `set_configuration`, claim/release via `usb.util` helpers
- `src/brother_printer/cli/main.py` -- Click-based `discover` subcommand
- `tests/transport/` and `tests/cli/` -- unit tests for protocol, discovery, error mapping, USB transport, CLI, and opt-in hardware smoke test
- `packaging/udev/99-brother-ptouch.rules` -- sample udev rule; `99-brother-ptouch_devcontainer.rules` -- dev-only rule (`0666`) for rootless Podman
- `.devcontainer/docker-compose.project.yaml` -- USB passthrough (`/dev/bus/usb`), `keep-groups`, `device_cgroup_rules`
- `.devcontainer/scripts/post-create.sh` -- project venv console scripts on PATH
- `docs/install/linux-usb.md` -- Linux USB setup, udev, and rootless Podman troubleshooting guide
- `docs/vendor/usb-ids.md` -- confirmed PT-E920BT product ID `0x224B`
- `justfile.project` -- `discover` recipe
- `pyproject.toml` / `uv.lock` -- pyusb + libusb backend dependencies

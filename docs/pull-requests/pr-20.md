# [PR 20](https://github.com/exoma-ch/brother-printer/pull/20) feat: CLI print command with tape selection and auto-cut

## Description

Implement the `brother-printer print` CLI command and `print_image()` library orchestrator for PT-E920BT. Users can print PNG (and other PIL-supported) images from the command line with tape width selection, auto-cut control, copies, and imaging options (threshold, rotate, margin). The orchestrator discovers the printer over USB, reads status, refuses to print when loaded tape does not match the requested width or the printer is not ready, then encodes and sends the raster job.

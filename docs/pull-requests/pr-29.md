# [PR 29](https://github.com/exoma-ch/brother-printer/pull/29) chore!: refurbish hardware print tests and trim driver imaging pipeline

## Description

Refurbishes the hardware print test suite and supporting tooling for the `brother-ptouch-driver` package, and trims the driver imaging pipeline. The hardware print matrix is reduced to physical-action checks (chained feed, cutter, half-cut) plus zero-tape mismatch/scaling guards, the legacy `qr_*`/`gray_*`/`distort_*` fixtures are replaced with per-width `label_*mm.png` text fixtures, and intent-based opt-in test recipes are added. Coverage is scoped to package `src` only, fixture-generation recipes are renamed for cross-package consistency, the driver imaging pipeline drops rotate/margin (now owned by `brother-ptouch-label`), and the label default font size is capped at 48px.

## Changes Made

- **Hardware print matrix refurbished** (`packages/brother_ptouch_driver/tests/hardware/test_print.py`, `conftest.py`)
  - Matrix reduced to physical-action checks (chained feed, cutter, half-cut) plus zero-tape `TapeMismatchError`/`ImageScalingError` guards; adds `print_png()` and `print_image(copies=2)` on the loaded tape
- **Fixture overhaul** (`tests/hardware/assets/`)
  - Replaced `qr_*`, `gray_*`, and `distort_100` assets with per-width `label_{width}mm.png` text-only fixtures (height = tape print area, stating mm/pixels and rendered font size); updated `generate_fixtures.py`; removed the `qrcode` dev dependency (`pyproject.toml`, `uv.lock`)
- **Scoped, intent-based test recipes** (`justfile.project`, `TESTING.md`)
  - Added `just test-connect`, `just test-print`, and `just test-all`; renamed `gen-test-images` → `gen-fixtures-driver` and `gen-text-images` → `gen-fixtures-labels`
- **Coverage scoped to package src** (`justfile.project`)
  - `just test-cov` now reports coverage for `packages/*/src` only
- **Driver imaging pipeline trimmed** (`brother_ptouch_driver/cli/main.py`, `imaging/raster.py`, `imaging/__init__.py`, `printing.py`) — BREAKING
  - Removed `--rotate`/`--margin` CLI flags and the `rotate`/`margin` params from `print_image`, `print_png`, `print_strip`, and `image_to_raster`; removed `apply_rotation`/`apply_margin` helpers (rotation/margins belong in `brother-ptouch-label`). Pruned obsolete `tests/imaging/test_raster.py` and `tests/cli/test_print_command.py` cases
- **Label default font size cap** (`brother_ptouch_label/cli/main.py`, `text.py`)
  - Auto-fit default font size capped at 48px; added golden `default_cap_36mm.png` and updated `test_text.py`/`test_golden.py`

  - Removed `apply_rotation` and `apply_margin` from the imaging pipeline; rotation and margins belong in `brother-ptouch-label`

# [PR 17](https://github.com/exoma-ch/brother-printer/pull/17) feat(imaging): add image-to-raster QR pipeline

## Description

Adds an image-to-raster pipeline that converts PIL images into 70-byte P-touch raster lines, tuned for sharp QR codes at 360 dpi. The pipeline uses strict thresholding (no dithering), integer nearest-neighbor scaling, rotation, and margin support. Non-integer scale factors that would distort QR modules are rejected. Adds `TapeWidth.print_area_left_pins` for print-head positioning and locks Pillow as a dependency.

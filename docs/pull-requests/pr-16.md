# [PR 16](https://github.com/exoma-ch/brother-printer/pull/16) feat: P-touch raster protocol encoder and status decoder

## Description

Implement the P-touch raster protocol encoder and 32-byte status reply decoder as pure functions in `src/brother_printer/protocol/`. Adds constants, enums, `encode_job()` for minimal single-page jobs, status decoding with TZe tape-width mapping and human-readable errors, golden-file tests, and opt-in hardware smoke tests for print and status round-trip on a connected PT-E920BT.

## Changes Made

- **`src/brother_printer/protocol/`** — protocol layer implementation
  - `constants.py` — raster command constants and tape-width tables
  - `enums.py` — media type, tape color, error codes, print phase, notification flags
  - `encoder.py` — pure-function encoder for init, status request, mode select, raster lines, print, eject; `encode_job()` for minimal single-page jobs
  - `decoder.py` — 32-byte status reply parser with TZe width mapping and error messages
  - `__init__.py` — public API exports
- **`tests/protocol/`** — unit, golden-file, and opt-in hardware tests
  - `test_constants.py`, `test_enums.py`, `test_encoder.py`, `test_decoder.py`
  - `golden/minimal_job_24mm.bin`, `golden/status_ready_24mm.bin`
  - `test_hardware_print.py`, `test_hardware_status.py` (pytest marker `hardware`)
- **`src/brother_printer/transport/usb.py`** — detach kernel driver before set_configuration for devices bound by the kernel
- **`tests/transport/test_usb_transport.py`** — coverage for kernel-driver detach path
- **`CHANGELOG.md`** — Unreleased entries for encoder/decoder, hardware tests, and eject fix

# [PR 12](https://github.com/exoma-ch/brother-printer/pull/12) docs: collect official PT-E920BT documentation

## Description

Collect official Brother PT-E920BT documentation under `docs/vendor/` for in-repo reference
and AI-assisted development. Adds provenance index, fetch/convert scripts, grep-friendly text
dumps of the User's Guide and a 360 dpi raster command reference (PT-P900-family proxy),
extracted USB/tape fact files, and applicability stubs where command modes do not apply.

## Changes Made

- **`docs/vendor/INDEX.md`** — Provenance table (URLs, versions, SHA256, applicability, model comparison)
- **`docs/vendor/README.md`** — Fetch/regenerate instructions
- **`docs/vendor/fetch.sh`** / **`docs/vendor/convert.sh`** — Download PDFs to gitignored `cache/`; convert with `pdftotext`
- **`docs/vendor/pt-e920bt-user-guide.md`** — User's Guide text dump (PT-E720BT / PT-E920BT)
- **`docs/vendor/ptouch-raster-command-reference.md`** — Raster command reference text dump (PT-P900-family proxy for 360 dpi / 560-pin head)
- **`docs/vendor/ptouch-template-command-reference.md`** — Applicability stub (PT-E920BT not on Brother command-reference or SDK P-touch Template matrix)
- **`docs/vendor/escp-command-reference.md`** — Applicability stub (PT-E920BT advertises Raster + Mobile SDK only)
- **`docs/vendor/usb-ids.md`** — Canonical USB facts (VID `0x04F9`, PID TBD → #4, endpoint layout from family appendix)
- **`docs/vendor/tze-tape-widths.md`** — TZe widths (3.5–36 mm) and printable pixel counts at 360 dpi
- **`.pre-commit-config.yaml`** — Exclude vendor PDF text dumps from typos/pymarkdown (hex bytes in raster examples)
- **`CHANGELOG.md`** — Unreleased entry for #1

# [PR 26](https://github.com/exoma-ch/brother-printer/pull/26) test: homogenize hardware suite, document print matrix, fix chunked USB writes

## Description

Adds root `TESTING.md` documenting how to run unit and hardware tests, the software/hardware suite layout, per-tape behavior, coverage gaps, and the P0–P3 minimal-tape print matrix. Consolidates all opt-in hardware tests under `tests/hardware/` with shared `conftest.py`, removing scattered `*_hardware*` modules in `tests/protocol/` and `tests/transport/`.

Also fixes `UsbTransport.write()` to loop bulk OUT transfers in 16 KiB chunks so large multi-page strips are not truncated when the printer throttles USB intake. Adds grayscale and `distort_100.png` fixtures for threshold and `allow_distortion` hardware checks; P1 now sends one chained `encode_strip_job` instead of repeated `print_image` ejects.

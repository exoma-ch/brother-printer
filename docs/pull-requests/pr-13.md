# [PR 13](https://github.com/exoma-ch/brother-printer/pull/13) docs: publish build-strategy ADR for PT-E920BT

## Description

Prior-art survey of eight open-source Brother label-printing projects, with a build-strategy ADR for PT-E920BT. The ADR records two decisions: use the P-touch **raster** protocol (not ESC/P or QL raster) and implement a **from-scratch Python** library in this repo, treating prior art as reference only.

Covers all issue #2 acceptance criteria: project comparison, user-pain themes from open issues, PT-E920BT support status (none found; PT-P910BT proxy manual is closest), and rejected alternatives (fork/wrap `ptouch-print`, extend `brother_ql`, ESC/P libraries, Mobile SDK).

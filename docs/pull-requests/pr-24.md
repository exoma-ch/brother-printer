# [PR 24](https://github.com/exoma-ch/brother-printer/pull/24) feat: add status, discover --status, and info tapes commands

## Description

Adds live printer status reporting and reference tooling to the `brother-printer` CLI and library, all routed through the public `brother_printer` API (per #18). Introduces `brother-printer status` for a single printer, a `discover --status` flag to query every connected printer, and an `info tapes` reference command. The library gains public `query_status()` and `select_printer()` helpers plus a `PrinterStatus` re-export. Verified end-to-end against a live PT-E920BT (36 mm yellow laminated tape reported as Ready). Includes a merge of the latest `dev` (half-cut label strips, #21/#23), with the status API and half-cut features reconciled.

## Changelog Entry

### Added

- **CLI status, discover --status, and info tapes** ([#8](https://github.com/exoma-ch/brother-printer/issues/8), [#19](https://github.com/exoma-ch/brother-printer/issues/19))
  - `brother-printer status [-p ID]` shows loaded tape, color, media type, phase, and error state
  - `brother-printer discover -s/--status` queries each printer with graceful per-device failure handling
  - `brother-printer info tapes` lists supported TZe widths and printable pixel widths at 360 dpi
  - Library API: `query_status()`, `select_printer()`, and `PrinterStatus` re-export; CLI routes through `brother_printer` only ([#18](https://github.com/exoma-ch/brother-printer/issues/18))

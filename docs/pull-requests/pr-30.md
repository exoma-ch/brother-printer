# [PR 30](https://github.com/exoma-ch/brother-printer/pull/30) chore: add loopback transport and end-to-end print golden

## Description

Implements the in-memory loopback transport and golden-file harness from #9, and (folded into the same issue) tightens the library API so imaging error types are no longer imported directly by the CLI.

`LoopbackTransport` records every `write()` and replays canned `read`/`read_exact` replies, implementing the `Transport` protocol as a hardware-free drop-in for `UsbTransport`. It enables a true end-to-end `print_image` test that drives the real imaging and encoder path (no `encode_job`/`image_to_raster`/`decode_status` mocking) and compares the captured byte stream against a committed golden — closing the gap where the full print path was previously only exercised on physical hardware.

## Changes Made

- **`LoopbackTransport`** (`transport/loopback.py`, exported from `transport/__init__.py`)
  - In-memory transport recording writes and replaying canned replies, with context-manager support
- **`Transport` protocol widened** (`transport/base.py`)
  - Adds `read_exact`, which the print orchestration already relied on; conformance stub updated (`tests/transport/test_transport_protocol.py`)
- **End-to-end loopback golden test** (`tests/test_printing_loopback.py`, `tests/golden/print_image_24mm.bin`)
  - `print_image` driven through `LoopbackTransport` over the real imaging + encoder path; captured job compared to a committed golden; regenerate with `UPDATE_GOLDEN=1`
- **Imaging errors routed through the library API** (`__init__.py`, `cli/main.py`, `tests/cli/test_cli_imports.py`, `docs/adr/0002-architecture.md`)
  - `ImagingError`/`ImageScalingError` re-exported from `brother_ptouch_driver`; CLI imports them from the library surface; import guard now forbids direct `imaging` imports; ADR-0002 wording updated
- **Docs** (`TESTING.md`, `CHANGELOG.md`)
  - New "Golden files" section documenting `LoopbackTransport` and the `UPDATE_GOLDEN` regeneration flow; changelog entries under Unreleased
